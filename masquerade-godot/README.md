# Morbid Masquerade (Godot)

The Steam version of Morbid Masquerade. The plan is in [docs/godot-remake-plan.md](../docs/godot-remake-plan.md).

- `rules/`: the game rules, ported from `server/src/crowd/`. `CrowdMatch` runs a round; each room is a
  `CrowdRules` subclass in `rules/modes/`; `QuickPlayRound` adds the round timer and scores.
- `night/`: the full night (the main mode; its name is still to be decided), ported from `server/src/party/`.
  `MasqueradeNight` holds the night, `NightRound` runs the layers during a room, `NightSession` drives a whole night
  (board, rooms, results, shop, Mole vote, Last Dance, standings).
- `tests/`: headless tests, including the parity test against rounds recorded on the Node server.
- `view/`: the 3D picture. `CrowdView3D` draws a round from the view dictionaries the rules hand out, so it
  works the same for a local round or one sent over the network. Rooms, figures, masks and props are placeholders;
  see [view/README.md](view/README.md) for swapping in modelled art.
- `app/`: the main scene (`Main.tscn`: title, menu, how to play, options, join screen) and two autoloads:
  `Settings` (saved to `user://settings.cfg`) and `Audio` (music and sound effects on their own buses).
- `ui/`: the menus and screens built in code: `MenuList` (a list driven by any keyboard or controller),
  `OptionsMenu`, `Lobby` (the join screen) and `BetweenScreens` (every screen between rooms). `UiStyle` holds the
  colours and fonts.
- `game/`: the game scene. `PlayDriver` runs quick play or a night for the seats that joined (keyboard, each
  controller, computer players), including controller aiming and rumble; `GameHud` is the HUD; `game.gd` adds the
  pause menu, music and sounds.
- `audio/`: music and sound effects, generated by `audio/make_audio.py` (needs numpy and ffmpeg) from the same
  recipes as the web client. Re-run it to change them.
- `debug/`: a flat test bench with the same driver, and `FlowCheck.tscn`, which plays a whole night or quick-play
  set through the real menus and screens.

Open this folder in Godot 4.7 and press Play. The title screen waits for any key or button; press Enter or A on a
controller to join a seat. Keys in a room: WASD move, Shift run, E act, click to shoot, Esc pauses. Controllers:
left stick, B run, A act, X or RT shoots, Start pauses. Main scene arguments for screenshots: `--screen=title|menu|
how|options|lobby_quick|lobby_night` and `--guests=N`.

Screenshots without a screen (Linux, with Xvfb):

```
xvfb-run -a godot --path masquerade-godot --rendering-driver opengl3 --write-movie /tmp/shot.png \
  --fixed-fps 20 --quit-after 30 -- --screen=menu
xvfb-run -a godot --path masquerade-godot --rendering-driver opengl3 --write-movie /tmp/shot.png \
  --fixed-fps 20 --quit-after 120 res://game/Game.tscn -- --demo --room=marked      # or --night
```

Play a whole night through the menus without a screen (prints FLOW OK):

```
godot --headless --fixed-fps 20 --path masquerade-godot res://debug/FlowCheck.tscn -- [--quick | --solo]
```

## Builds

Install the Godot 4.7.1 export templates, then:

```
godot --headless --path masquerade-godot --export-release "Windows" builds/windows/MorbidMasquerade.exe
godot --headless --path masquerade-godot --export-release "Linux" builds/linux/MorbidMasquerade.x86_64
```

`builds/` is not committed. The Windows build is unsigned and uses Godot's icon on the .exe until rcedit is set up.

## Tests

```
GODOT=/path/to/godot masquerade-godot/tests/run.sh          # everything
GODOT=/path/to/godot masquerade-godot/tests/run.sh marked   # names containing "marked"
```

If you change the rules on the server, re-record the parity rounds from the repo root and make the Godot port
match again:

```
server/node_modules/.bin/tsx masquerade-godot/tests/parity/record.ts
server/node_modules/.bin/tsx masquerade-godot/tests/parity/record_nights.ts
```
